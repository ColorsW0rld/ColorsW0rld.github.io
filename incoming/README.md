# 文章收件目录

把 Save Page WE 保存的 `.html` 文件直接上传到本目录，再点击 **Commit changes** 提交到 `main`。无需重命名文件或创建年份目录。

提交后会自动归档并更新首页。成功归档的文件会从这里移入 `articles/发布年份/`；失败或重复的文件保留在这里，原因见 [Actions 运行摘要](https://github.com/ColorsW0rld/ColorsW0rld.github.io/actions/workflows/archive-articles.yml)。

完整操作见 [README](../README.md)。请保留本说明文件。
